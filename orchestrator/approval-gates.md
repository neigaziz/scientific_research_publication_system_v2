# Human approval gates

| Gate | Required before | Evidence to present |
|---|---|---|
| H1 | Final research question/objectives/novelty position | Evidence map, contribution, feasibility, limits |
| H2 | Protocol and design/analysis plan | Design rationale, assumptions, power/sample-size rationale where applicable |
| H3 | Material exclusions, filtering, imputation or transformations | Counts, reasons, sensitivity plan and reproducible code |
| H4 | Final model/primary analysis decisions | Estimand, model, assumptions, diagnostics and alternatives |
| H5 | Material biological interpretation and claims | Claim-evidence matrix, uncertainty and alternatives |
| H6 | Authorship, ethics, conflicts, data/code declarations | Actual author/institution confirmations |
| H7 | Journal choice and submission | Current official instructions, final files and co-author approval |
| H8 | Material reviewer responses and resubmission | Comment matrix, changes and new analysis/experiment records |

The agent may prepare recommendations but must not impersonate an author, fabricate approvals or submit externally without explicit human authorisation and supported tools.
