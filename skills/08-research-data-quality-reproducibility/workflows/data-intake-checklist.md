# Research data intake checklist

- Preserve original source files as immutable read-only inputs.
- Create file manifests and checksums.
- Record provider, retrieval date, permissions, data dictionary and version.
- Validate columns, types, units, unique identifiers and allowed ranges.
- Inspect missingness, duplicates, joins, outliers and temporal consistency.
- Record each exclusion/transformation, rationale and code.
- Separate raw, interim and derived/final data.
- Track software/package versions, seeds and runtime settings.
- Reconcile sample counts at each stage.
- Confirm that outputs can be recreated from documented inputs and code.
