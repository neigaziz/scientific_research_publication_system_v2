# Reference and decision notes — Bioinformatics and Computational Biology

This is a curated knowledge index, not an authoritative textbook. Add only reviewed, versioned references.

## Reference practices
- Prefer primary research, official standards, software/database documentation and publisher instructions.
- Record author/organisation, title, year/version, DOI/URL, access date and exact page/section supporting the statement.
- Distinguish peer-reviewed papers, preprints, technical documentation, reviews, datasets and opinion.
- Do not treat journal prestige, citation counts or model-generated summaries as substitutes for methodological appraisal.
- Re-check time-sensitive policies and software requirements at the point of use.

## Domain knowledge to curate
For this capability, curate accepted terminology, method-selection rules, model assumptions, known failure modes, reporting expectations, benchmark examples and domain-reviewed test cases.

## Evidence hierarchy
1. Original project data and analysis outputs for project-specific claims.
2. Primary peer-reviewed studies for empirical findings.
3. Official software, database and standards documentation for technical requirements.
4. Systematic reviews and high-quality reviews for context and synthesis.
5. Other sources only with explicit justification.

A reference is not fully verified until its metadata and claim-level relevance have both been checked.
